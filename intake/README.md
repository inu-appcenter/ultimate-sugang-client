# intake/ — 원본 명세 투입함

여기에 원본 명세 파일을 아무 형식·아무 이름으로 넣으면 된다(제품 명세, API 문서, 와이어프레임 설명, 디자인 가이드 등 — 하나여도, 여러 개여도 됨).

그 다음 Claude Code 에서:
```
이 명세로 초기화해줘   (또는 harness-init 스킬 언급)
```
`harness-init` 이 이 폴더를 스캔해 `.claude/spec/` SoT 6문서와 빌드 체크리스트를 생성한다. 경로를 직접 지정하거나 대화에 명세를 붙여넣어도 된다.

이 폴더는 하네스 입력용이며 빌드 산출물이 아니다 — init 완료 후 사실의 권위는 `.claude/spec/` 으로 넘어간다(원본은 보관용).
