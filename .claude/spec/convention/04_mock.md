# convention 04 — mock 어댑터·시드·검증 시뮬레이션

> 권위: D1 · D25 · D26 · D41 · D42 · D43 · D44 · `spec/02_api_spec.md` §4.
> **mock 어댑터는 버리는 코드가 아니다** — 서버 계약이 확정된 뒤에도(D55) `VITE_API_ADAPTER=mock` 으로
> 되돌릴 수 있게 유지한다. 로컬 연습과 Playwright 스모크가 이 어댑터 위에서 돈다.

## §1 어댑터 동작 (`api/mock/mockApi.ts`)

- 인메모리 시드 + **서버 지연 시뮬레이션 200~800ms**(원§12) + 서버 검증 시뮬레이션(02 §4-1) + 이수구분 파생(02 §4-2).
  실서버는 인위적 지연을 넣지 않지만(D55-6) **mock 의 지연은 연습용으로 유지**한다.
- 시뮬레이션하지 않는 것: 동시 경쟁 · 대기열 · 서버 시계 · 확률적 실패율(02 §6).
- `VITE_MOCK_FAIL=session` 이면 **신청/취소만** `SESSION_EXPIRED` 를 던진다(D44).
- 신청내역은 학번별 모듈 싱글턴 Map — 새로고침하면 초기화된다. **초기 신청내역은 0건**(D43, 조사 당시 실제 상태).
- 교양 조회는 코드값(02 §5-1)을 이름으로 바꿔 필터한다(D29). 이수영역 미지정이면 이수구분 전체.
- 타학과는 개설학과 완전일치 필터(D30 — 이름이 곧 값). 연계전공은 관측 시드가 없어 **빈 결과**다.
- 과목명 조회는 과목명 또는 학수번호 부분 일치 — 실제 판단은 서버 영역이고 여기서는 근사다.

## §3 서버 검증 시뮬레이션 (`api/mock/validate.ts`)

**실 규칙은 백엔드 소관**이다. 여기서는 02 §4-1 순서와 시드 §2.4 충돌 테스트 세트가 통과하도록 재현할 뿐이다.

### 3.1 검증 순서 (D41 — 바꾸지 말 것)
```
시간표 중복 DUP_TIME  →  동일 과목명 DUP_SUBJECT  →  학점 상한 CREDIT_EXCEEDED  →  정원 CLASS_FULL
```
- **동일 과목명은 시간 중복과 독립**이다 — 시간이 안 겹쳐도 과목명이 같으면 차단한다(실측).
- CAPTCHA 는 이 순서 밖의 별도 게이트다(D34).
- 정원(`CLASS_FULL`)은 프론트가 `isClosed` 행을 `마감` 버튼으로 **사전 차단**하므로 실제로는 도달하지 않는다.

### 3.2 시간표 비교는 반교시 단위
- 시간표 원문을 `요일:반교시` 슬롯 집합으로 바꿔 비교한다. 교시를 앞(A)/뒤(B) 반교시로 쪼개야
  `1-2A`(1교시~2교시 앞)와 `2B-3`(2교시 뒤~3교시)가 겹치지 않는다(시드 §2.4 "교차 배치").
- 반교시 인덱스: N교시 앞 = `2N-1`, 뒤 = `2N`. 야간(`야N`)은 별도 네임스페이스로 둔다.
- 토큰 형태: `N` · `NA`/`NB` · `N-M` · `N-MA` · `NB-M` · `NB-MA` · 야간 `야N`. 괄호로 시작하면 강의실이라 건너뛴다.

### 3.3 이수구분 파생 (D42 — 근사)
```
개설학과 === 소속학과 → 조회 값 유지
전공 계열(MAJOR_COURSE_TYPES) → 일반선택
그 외(교양 등) → 유지
```
시드 §8 실측을 근사한 규칙이고 **실 규칙은 백엔드 소관**이다. 프론트는 조회 값(`courseType`)과
신청내역 값(`resolvedType`)을 각각 표시할 뿐 재계산하지 않는다(02 §4-2).

### 3.4 학점 상한 (D26)
기본 20(기준 17~19, 부득이 20) · GPA 3.5↑ 21 · GPA 4.0↑ 24. 서버 산출값을 시뮬레이션한 것이며
프론트는 "합계 > 상한 차단" 메시지만 낸다.
